# documents

A Flutter base app.

## Getting Started

This project is a starting point for a Flutter application.

### Prerequisites

- [Flutter SDK](https://flutter.dev/docs/get-started/install) (>=3.3.0)
- Android Studio or Xcode for device emulation

### Running the App

```bash
flutter pub get
flutter run
```

### Running Tests

```bash
flutter test
```
